# 🛒 E-Commerce Customer Analytics & Revenue Prediction Pipeline

An end-to-end data engineering and predictive machine learning pipeline architected to process real-time e-commerce checkout attributes and forecast net transactional revenue.

## 🛠️ Tech Stack & Methodology
* **Data Engineering:** Managed operational data gaps using robust Median Imputation Strategy.
* **Exploratory Data Analysis:** Developed a Feature Correlation Heatmap to analyze price, discount, and shipping dependencies.
* **Ensemble Learning Engine:** Deployed a Random Forest Regressor to capture complex, non-linear market noise.
* **Model Serialization:** Exported the trained framework into a standalone binary file (`ecommerce_sales_model.pkl`) for warning-free deployment.

## 📈 Key Outcomes
* **Elite Precision:** Achieved a stable **99.41% R² Variance Score**.
* **Production Ready:** Designed for instantaneous real-time inference checks.
